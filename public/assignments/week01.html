Homebrew Install Command 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Generate SSH Key 
ssh-keygen -o

Installing Git Locally

  1. Installed Homebrew from the Mac Terminal. Xcode and Git installed automatically.

  2. Set up the SSH key, choosing the destination as the home folder. The file is named with extension .ssh. The dot makes it a hidden folder.

  3. I didn't add a passcode, but it is good to add one. And don't publish the private key anywhere — the private key is the random art image inside the box in the terminal.
Copy Public Key 
cat ~/.ssh/id_ed25519.pub

Setting up Git Tunnel

  1. Now that a public key & private key pair has been created locally for authentication, copy the public key from terminal using the cat command.

  2. Logged into GitHub, added a new blank project and named it Tom - Fab-Academy.

  3. Go to Git Preferences and add the public key that was copied. This creates a secure tunnel between the local machine and the remote repository — the public key acts as the lock and only the local private key can open it.
Clone Repository 
git clone https://github.com/USERNAME/REPOSITORY.git

Cloning the Repo

  1. Copied clone url from git. Make sure you are copying the url for clone with SSH and not with HTTPS.

  2. Run the clone command locally to copy the existing GitHub files into local machine.

  3. Use add, compile and push commands from the terminal to move local changes to online GitHub repository.
