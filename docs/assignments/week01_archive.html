Setting up Git

  1. Installed Homebrew from the Mac Terminal using the below command. Xcode and Git installed automatically.
    2. /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  2. Set up the ssh key using the below command.
    Note: I chose the destination folder as .ssh in home folder. The dot makes it a hidden folder. I didn't add a passcode, but it is good to add one. And don't publish the private key anywhere. Private key is the randomart image inside the box.
    3. ssh-keygen -o
  3. Copied the public key from terminal using the below command. This creates a public key & private key pair for authentication.
    4. cat ~/.ssh/id_ed25519.pub

  4. Logged in, added a new blank project in https://git.fablabkerala.in/ and named it Tom - Fab-Academy

  5. Added the public key I had copied in Git Preferences.

  6. Copied clone url from git.
  7. Executed the below clone command to create a Local Repo.
    Note: The URL copied earlier needs to be added here and a tunnel is established between the lcoal repository on your system and the one on the git cloud. The tunnel's lock is the public key and the only key that will fit the lock is the private key pair you generated on your local system. 
    8. git clone git@gitssh.fablabkerala.in:tom/tom-fab-academy.git
